## 四、证据说明

| 等级 | 证据类型 | 能证明 | 局限 |
|---|---|---|---|
| ① | **git 提交记录** | 某日确有开发活动、提交时间戳、提交内容 | 仅记录「提交那一刻」，不含写内容/调试/学习时间 |
| ① | **Claude Code 会话时间戳** | 某时段的连续工作时间 | 仅记录使用该工具的时段 |
| ② | **本人自报排班** | 完整工作时段（工具未覆盖部分） | 需以①类记录交叉佐证 |

**两个项目均具备客观代码证据**：

- **小程序 A**：仓库 `aishixi`，122 次提交，12 个有提交日（8/06–8/25）
- **小程序 B**：仓库 `xin xiangmu`，44 次提交，8 个有提交日（8/27–9/06）

**总体说明**：本项目为**远程实习**，工作时段集中在**夜间至凌晨（21:00–次日 05:00）**。两个仓库的提交时间戳（大量落在 00:00–05:00 与 21:00–23:00）与所述作息吻合。工具类记录只能覆盖部分时间，故工时以「自报排班 + git 提交 / 会话记录佐证」相结合的方式统计。
